# Isaafi Backend — NVIDIA + Gemini pipeline

Pipeline: image → classifier → RAG retrieval (Nemotron Embed + FAISS) → Nemotron 3.5 Lightning
(Gemini as automatic fallback) → structured JSON response.

```
app/
├── main.py              # FastAPI app entry
├── config.py            # env vars, model names, paths — read from here, not os.environ directly
├── api/routes.py         # the /analyze endpoint, orchestrates the whole pipeline
├── services/
│   ├── classifier.py     # image -> (condition, confidence) — currently a Gemini-vision placeholder
│   ├── nvidia_llm.py      # Nemotron 3.5 Lightning — primary reasoning/generation
│   ├── gemini.py          # fallback reasoning + the classifier placeholder
│   ├── embeddings.py      # Nemotron 3 Embed 1B wrapper
│   ├── retriever.py       # FAISS lookup over the knowledge base
│   └── safety.py          # optional NVIDIA Content Safety layer (currently a no-op)
├── schemas/first_aid.py   # the structured response shape
└── prompts/first_aid_prompt.txt
knowledge/                 # the ONLY source of medical content the LLM is allowed to draw from
vector_store/               # generated by scripts/build_embeddings.py — not hand-edited
scripts/build_embeddings.py # run this once, and again whenever knowledge/*.md changes
```

## 1. Get your API keys

- **NVIDIA**: https://build.nvidia.com → sign in → https://build.nvidia.com/settings/api-keys → create a key (`nvapi-...`).
- **Gemini** (fallback, free): https://aistudio.google.com/apikey — no card required.

## 2. Set up

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # paste both real keys in
```

## 3. Build the vector store (do this before first run, and again after editing knowledge/*.md)

```bash
python scripts/build_embeddings.py
```
This reads every file in `knowledge/`, embeds each `##` section with Nemotron 3 Embed 1B, and writes
a FAISS index to `vector_store/`. It needs your `NVIDIA_API_KEY` set already.

## 4. Run the server

Run this from the `backend` folder (not from inside `app/`) so the imports resolve correctly:
```bash
uvicorn app.main:app --reload --port 8000 --host 0.0.0.0
```

Test:
```bash
curl -X POST http://localhost:8000/analyze -F "image=@test.jpg"
```

## How the fallback works

`api/routes.py` calls `nvidia_llm.generate_guidance()` first. If that raises for any reason (rate limit,
outage, malformed response), it automatically retries the same request through `gemini.generate_guidance()`
instead — same prompt, same expected JSON shape. The response includes `"source": "nemotron"` or
`"source": "gemini"` so you always know which one actually answered, which is useful both for debugging
and for the "compare NVIDIA vs Gemini" evaluation the hackathon asks for.

## What still uses Gemini permanently (not just as fallback)

`services/classifier.py` currently calls Gemini's vision model to classify the photo, because the custom
computer-vision model isn't trained yet. Once it is (see the separate training guide), swap the body of
`classify()` in that one file for local inference — nothing else in the pipeline needs to change.

## Safety layer

`services/safety.py` is a deliberate no-op right now (`ENABLE_SAFETY_CHECK = False`), matching the
handout's guidance to add it only after the core pipeline works. Flip that flag and fill in the TODO
once you're ready to wire in an NVIDIA content-safety model call.

## Never commit `.env`

It's already in `.gitignore`. Only `.env.example` (with placeholder values) should ever be committed.
